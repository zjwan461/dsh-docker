# 验证记录（本机实测，2026-11-12 ~ 11-13）

只记**实际跑过**的。没跑过的写"未验证"，不写成结论。

---

## 1. 0.4MP 三条基础验证

| 条 | 参数 | 结果 |
|---|---|---|
| **V1 二维漫剧** | t2v / 9:16 / 5.167s(124f) / 0.4MP / 8步 | 画风守住（赛璐璐、粗线条、平涂，未滑向实拍）；竖屏正确。**但**：运动量极低（小幅度推镜≈不动）；街景自动长出**乱码招牌**；峰值 −0.3dB |
| **V2 三人站位** | r2v / 16:9 / 12.25s(294f) / 0.4MP / 4步 | 三角站位成立（女左前景背影、外星人中景、男右后景）；第二镜切单人特写正确；第三个人物纯文字描述也稳住；无明显串嘴 |
| **V3 六拍打斗** | t2v / 16:9 / 8s(192f) / 0.4MP / 8步 | 有打击感（起手、腾空、环轨、特写、扬尘）；**但**对手在末两镜消失、收尾没定格 |

共同结论：0.4MP 只验证结构；H3 原生音轨偏响；插件状态会滞后（`queued` 但产物已在 output）。

## 2. qa.py 实测（同三条）

|---|---|---|---|
| V1 | −14.5 LUFS | −0.3 dBTP | 0 |

## 3. V1b 大幅度运镜复测

同提示词把 `small amplitude at slow speed` 改成 `large amplitude at fast speed`：五帧从全身远景明显推到面部特写，**运动可见**，画风仍守住。证实"打样档要放大幅度"。

## 4. r2v 身份与站位

2 张参考图 / 4s(107f) / 4步 turbo：

- **保住**：身份、服装、身高比、**左右站位**（外星人左前景、地球人右背景）
- **没保住**：写了 `eyes on each other` 仍**看向镜头**（视线是弱指令）；参考图没有的特征（琥珀眼、额头印记）不会补

## 5. Hub vs Chain（关键）

同锚点四段 i2v 4s/0.4MP/8步、提示词完全相同。链 A→B→C，Hub 锚点→D。

| 指标 | 链式 | Hub |
|---|---|---|
| 亮度相对锚点 | −2.3 / −4.4 / **−7.2**（3跳 −8.6%） | **−2.5（1跳）** |
| 每个接缝 PSNR | 33.8 / 34.2 dB | 33.3 dB |
| 第 3 跳 vs 锚点 | **13.1 dB** | — |

每个接缝单独看都好，三跳后整体偏掉——**漂移在接缝之间**。Hub 不累积。另：段内亮度会自己回弹 ±4（比每跳损失还大），所以"链完统一拉亮"不可靠。

## 6. 后期链路

三段素材（画幅不齐）→ `finish.py`：1920×1080/24fps/25.458s、**−16.0 LUFS / −2.0 dBTP**、自动字幕按 17k+5 排、`qa.py` 全绿。

小坑：loudnorm 输出采样率不固定（曾跑到 96k），已强制 48k。

## 6.5 图+音对口型（U11）

4s / 480×864 / 0.4MP / turbo 4step：**跑通**。107 帧、4.458s、48k 音轨，身份稳定、嘴型随音频开合，耗时 ~5 分钟。
坑：`ref_images` 必须走 `ZealmanH3LoadImageToRefImages` 的 bundle；音频路径要带子目录；可整条删掉 whisper 转录链直接给 prompt；分辨率用 `WJILatentPreset` 自定义 480×864。详见 `talking-head.md` §2.1。

## 7. 换脸（Character Swap LoRA）

- 三个 LoRA（character_swap v1.1 / head_swap v1.0 / preprocessor_map）**装好即被识别**，无需重启。
- 3s/0.4MP/r2v/20步：参考图身份四帧稳定。
- **API 直跑成功**：原片男人 → 虚构外星人，场景/机位/呼吸保留。见 `face-swap.md` §11。

## 8. 声音（人耳）

- 男声清楚区分；**两个女声听不出区别**。
- 实测 F0：女 ≈212Hz / 外星人 ≈165Hz（差 ~47Hz、区间重叠）/ 男 ≈122Hz。
- 结论：同性别音色必须拉**音区+年龄+质感**，否则改 TTS/克隆。

## 9. 插件/环境坑（已解决）

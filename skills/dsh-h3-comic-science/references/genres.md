# 平台爆款类型地图

做 AI 视频不是"选模型"，是"选类型"。同一个模型，换个类型就要换节奏、换镜头、换交付。这一份把各平台跑得动的类型拆成可执行的配方。

> 四条主线（漫剧 / 短剧 / 换脸重演 / 科普）在 §1–§3，其余是同一套底层能力的变体。**漫剧与短剧共用剧集语法，只差视觉介质。**

---

## 1. AI 漫剧（漫画介质的短剧，2–5 分钟竖屏）

**漫剧 = 短剧 + 漫画人物**，口播/对白驱动、旁白仅补，走电视剧/电影同款制片套路（见 `short-drama.md`）。

| 项 | 配方 |
|---|---|
| 钩子 | 前 3 秒给冲突/异常，不交代背景 |
| 节奏 | 每 15 秒一个反转；2–5s 一镜；断章不总结 |
| 视觉 | 漫画介质（赛璐璐/条漫/厚涂…全片锁定）；对白镜动态，静帧只作插入/空镜 |
| 声音 | **口播为主**（原生口播 / 克隆+对口型）；旁白 TTS 仅少量补充 |
| 坑 | 角色跨镜漂移（三视图+面部板）、做成"旁白+静帧"解说 PPT、画面"很满"但没信息 |
| 详见 | `manju-playbook.md`、`short-drama.md`、`image-pipelines.md` |

---

## 1.5 AI 短剧（红果 / 抖音）

**形态**：80 集 × 90–120 秒竖屏连续剧，写实/仿真人，靠表演和对白推进，每集一个回合 + 一个断章。

| 项 | 配方 |
|---|---|
| 单集结构 | 15 秒换挡四拍：抓人立事 → 正面交锋 → 亮牌翻转 → 余波钩子 |
| 断章 | 断在"反击前 0.5 秒"，不断在爽完之后 |
| 对白 | 4.5 字/秒；连续 15 秒 ≤95 字；占比 60–75% |
| 视觉 | 正反打 + 过肩 + 中景，**别怼脸流水线** |
| 合规 | 跨剧面部相似度 >65% 驳回；片头标"AI 辅助制作"；素材授权闭环 |

详见 `short-drama.md`。

## 2. 换脸 / 重演（MJ 演唱会、rapper swap）

**形态**：把经典画面/舞台的主角换成别人，保留原场景、运镜、表演；观众席也可换；配乐常换 AI 新唱。时长 15–90 秒。

**两条实现路线**：

| 路线 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A 首帧重建法**（爆款常用） | 图像编辑：原片截图 + 2 张人像 → 生成"新人站在原布景"的首帧 → 图生视频 + 表演提示词 | 不需要 guide video，托管 API 就能跑；口型/表演由模型现编，反而自然 | 动作不是原片逐帧复刻，是"重演" |
| **B Character Swap LoRA** | 原片进 `AddGuide` + 角色图 + `body_swap` | 动作/机位严格跟原片 | 需自建 ComfyUI + LoRA + AddGuide |

**首帧重建法的关键**（来自爆款复现）：

1. 图像编辑提示词要**逐条点名**：左边是谁、穿什么、右边是谁、穿什么、布景是什么（"无缝亮橙背景、金色复古麦克风"）。
2. `input_fidelity: high` 才保得住脸。
3. **裁成目标画幅再动画**——图生视频跟随首帧比例，3:2 会给你信箱边。
4. 表演提示词要**点名谁先唱**："左边穿黑高领的先说唱"，否则两人会合体或换衣服。
5. **要声音就明写**："audible rap vocals and a punchy beat"。
6. **禁字幕**（这类画面最容易自己长歌词条）。
7. **机位越无聊越保脸**：固定机位 + 慢推；大运镜是身份漂移的主因。

**合规红线**：换真实可识别的人需**本人授权**；平台对深度伪造有明确规则；必须标 AI。演示用虚构/已授权角色。

详见 `face-swap.md`（含 §11 API 接线与 route E）。

---

## 3. 科普 / 知识（外星人 + 地球人、Vibe 知识）

| 项 | 配方 |
|---|---|
| 结构 | 钩子 → 赌约 → 第 N 天 → 钻进比喻空间 → 兑现 → 揭晓代价 |
| 视觉 | 每个知识点一个"能进去的房间"（控制室/仓库/银行/工地） |
| 时长 | 2–5 分钟；14–15s 一段 |
| 数字 | 必须有出处；念全（"百分之二十八"） |
| 坑 | 数字念错、空间每镜不一样、结尾泄气 |
| 详见 | `science-playbook.md` |

**同类变体**：历史人物讲知识、假如系列、冷知识对比、产品原理拆解——骨架相同，只换"谁在讲"。

---

## 4. 口播 / 数字人（商单率最高的一类）

- **形态**：一个人对着镜头讲 30–90 秒，背景固定或轻微推拉。
- **做法**：定妆照 + 克隆音色（FishAudio）+ 对口型（U11）；或直接原生口播。
- **关键**：口型与音频逐句对齐；机位固定；手势要有但别抢脸。
- **坑**：长口播分段处跳变（用 `seam.py` 量）；音色跨集漂移（克隆解决）。
- 详见 `talking-head.md`、`native-dialogue.md`。

---

## 5. 亲情向 / 情绪向（商单率高）

- **形态**：老照片动起来、隔代对话、时光回溯。
- **做法**：老照片 → 图生视频（低幅度：眨眼、呼吸、微摇头）；配旁白 + 钢琴。
- **关键**：**动作越小越可信**；大幅动作会立刻"AI 味"。
- **坑**：把人脸做年轻/做老会失真；不要改脸，只让它动。

---

## 6. 动作迁移 / 舞蹈 / 武打

- **形态**：真人跳一段，换成角色/名人；或武打套招。
- **做法**：Wan Animate（`video/P02`）或 LTX；H3 只做"重演"。
- **关键**：全身、干净背景、姿态预处理；手部与快速转身是崩坏高发区。
- 详见 `alt-video-models.md`。

---

## 7. 音乐 MV / 歌词排版

- **形态**：歌词随节拍出现，画面卡点。
- **做法**：H3 原生渲染文字（这是**该用原生**的场景）+ 卡点剪辑。
- **关键**：可见文字必须与唱词**逐字一致**；每镜一个文字事件；不遮眼睛和嘴。
- 详见 `subtitles.md`（原生渲染那一节）。

---

## 8. 四宫格 / 分镜预览

- **形态**：一屏四格讲完一个段落，或做分镜预览。
- **做法**：LTX 四宫格（`video/Y08`）或 H3 一条生成 4 镜。
- **关键**：每格一个信息点；格与格之间景别要跳。

---

## 9. 动物拟人 / 宠物说话

- **形态**：真猫吐槽 / 拟人萌宠开口 / 萌系动物 CP 冒险（无对白）。
- **三条路线**：A 真动物+心声（嘴不动，H3 最好做）/ B 拟人开口（站着走路、有手有嘴，口型是风险）/ C 无对白动作喜剧（**最适合 H3**）。
- **关键**：① **别追求真口型**——动物没有可动人形口型，走心声或"节奏对得上"即可；② 每只动物要有**一个记号**（缺口耳）+ **一个招牌能力**（长身子→当桥，圆身子→当球），笑点从这里长；③ 一集一个地点、每格 ≥2 秒、一镜一个动作。
- 详见 `animal-anthropomorphic.md`。

---

## 10. 类型选择的三个硬约束

1. **时长决定结构**：15s 只能一个反转；60s 要三个；3 分钟要一条主线。
2. **口型要求决定路线**：要对嘴 → 克隆+对口型；不对嘴 → 原生口播或旁白。
3. **版权决定能不能发**：真人换脸、影视片段二创、品牌 logo，各有红线（见 `face-swap.md` §7、`delivery-and-qa.md` §6）。

---

## 10.5 开头：所有类型共用一套钩子库

不管做哪一类，**前 3 秒决定生死**。十种钩子（反常识/痛点/数字/损失/赌约/身份/对比/悬念/场景/结果前置）与各类型的首选搭配、口播节奏、A/B 方法见 `hooks.md`。

一句话版本：**替观众把问题说出来，不要介绍你要讲什么；第一句 = 第一帧。**

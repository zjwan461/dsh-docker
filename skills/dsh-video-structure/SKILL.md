# 短视频结构：片头、片尾与时长预算

## 0. 一条硬规则

观众不是"来看你的片子的"，是**划到了**。前 3 秒不给他一个"我正在想的问题"，后面再好也没用。

所以片头的任务不是"介绍"，是**替观众把问题说出来**。

## 1. 结构模板（72–90 秒 历史/科普/人物口播）

| 段 | 时长 | 作用 | 形态 |
|---|---|---|---|
| 冷开场 | 4–5s | 替观众提问 | 纯黑 + 居中大字 + 旁白 |
| 钩子 | 5–6s | 给一个反常识的答案 | 第一个实拍镜 + 标题卡 |
| 主体 | 60–75s | 讲清楚因果 | 分镜 + 旁白 |
| 总结 | 5–6s | 给一个能带走的东西 | 空镜/定格 + 一句转折 |
| 片尾卡 | 2–3s | 收口 + 引导 | 定格淡出 + CTA |

> 真实的例子：冷开场"历史上有没有什么冷门，但是战斗力极强的将领？"
> → 切开战场 + 标题卡 + 旁白"**有。**大唐开国，名将如云，可有一个人，专收这些名将的命。"
> → 主体十四镜 → 空战场"以他的本事，放在别的时代，足以裂土封王。可惜，他生在大唐。"
> → 定格淡出 + "他算英雄，还是祸乱？评论区聊聊。"

## 2. 冷开场：黑屏提问

**为什么有效**：画面信息为零，观众只能听你说；而你说的是他心里那个问题。
一旦他认领了这个问题，后面就是在"回答他"。

写法三原则：

1. **一句一个问号**。不要"你有没有想过，在漫长的历史长河中……"——两个从句还没问到点上，人已经划走了。
2. **不要术语**。"冷门但战斗力极强的将领"而不是"战功与史料记载显著不匹配的军事人物"。
3. **问"有没有/是什么"，不要问"你知道吗"**。"你知道吗"是在考他，"有没有"是在替他找。

时长：

- **4 秒以内说完**（旁白实际 3.5s 左右）。超过 5 秒就是"等"，不是"钩"。
- 黑屏**不要放 Logo、不要放动态背景、不要放 BGM 高潮**。任何画面信息都会分走注意力。

实现见 §8。

## 3. 提问和正文之间必须有"接话"

这是最容易漏的一步。从问句直接跳到正文第一句，观众会觉得"跳台"：

    ❌ "历史上有没有……战斗力极强的将领？" → "大唐开国，名将如云。"
    ✅ "历史上有没有……战斗力极强的将领？" → "有。大唐开国，名将如云，可有一个人，专收这些名将的命。"

接话只要两个字（"有。"/"还真有。"/"有一个。"），但它是**提问和故事之间的铰链**。
代价：正文第一句要跟着改，TTS 要重生成（几秒的事），别省。

## 4. 标题卡的时间锚点：不要写死绝对秒

**加片头之后，所有"从 0 开始算"的时间都会失效。**

> 真实案例：标题卡原来写死在成片的 `0.4s–3.6s`，正好压在第一个镜头上。
> 加了 5.2 秒黑屏片头之后，标题卡落到了**黑屏上**——观众只看到一片黑里浮出片名，
> 然后镜头才切进来。

规则：**标题卡锚到"第一个实拍镜头的起点"，不锚绝对时间。**

```python
t1 = next(x['start'] for x in timeline if x['id'] == 'S01')
Dialogue: 0, {t1+0.4}, {t1+3.6}, Title, ...
```

同理适用于：引文卡、数据卡、任何"跟某一镜绑定"的叠加层。**凡是加/删片段就要重算的，
一律写成相对锚点。**

## 5. 片尾：给一个"能带走的东西"

主体讲完因果，片尾要给的**不是总结，是判断**。

三条：

1. **不要重复主体说过的话。** 主体已经说过"他打败的唐将比大多数人见过的都多"，
   片尾再说一遍等于浪费 5 秒。
2. **用反事实 / "如果"**。这是最有效的句式：
   `以他的本事，放在别的时代，足以裂土封王。可惜，他生在大唐。`
   ——前半句抬高，转折词（可惜 / 只是 / 然而）落地，一句话完成情绪弧。
3. **落在"人"上，不落在"制度/时代"上**。观众记人，不记结论。
   "他终究只是一个人"比"这是集权体制的必然"好听一百倍。

一句话就够。片尾不是第二个主体。

## 6. 片尾不要和 CTA 抢同一块屏幕

> 真实案例：总结字幕放在 `total-5.5s`，CTA 放在 `total-4.4s`——两行字在屏幕下方叠在一起，
> 又挤又乱，而且观众不知道先看哪个。

做法：**片尾单独一张卡**。

- 取最后一帧 → 定格 2–3 秒 → 淡出到黑
- 总结字幕落在这张卡的**前 3/4**
- CTA 落在**最后 2–2.5 秒**，单独一行，居中或靠下

这样两个信息在时间上分开，不打架。

## 7. 时长预算：先算，再写

加片头片尾是要**付时长**的：

| 加的东西 | 代价 |
|---|---|
| 冷开场黑屏 | +5.2s |
| 片尾总结镜 | +5.9s |
| 片尾定格卡 | +2.5s |
| 合计 | **+13.5s**（72.6 → 86.2） |

抖音的完播率对时长很敏感，多 14 秒意味着**前段留存要更高**才能补回来。

三条路，先选一条再动手：

1. **接受**：钩子足够强时（历史/悬疑类），多出来的时长能被留存吃掉。
2. **砍一镜**：从主体里砍掉信息量最低的一镜（本项目候选是"称帝"或"攻俘"），换回 5.2 秒。
3. **压片头**：提问只留半句、或黑屏缩到 3 秒。

**判断规则：多出来的时长 ≤ 5 秒，接受；> 10 秒，先砍一镜再发。**
上线后看 3 秒跳出率，跳得多就回压片头。

## 8. 实现：三种卡 + 一层 ASS

### 黑屏提问卡

**音画必须分开生成**（一起生成时 `-frames:v` 会把音轨截断，见 `dsh-video-ffmpeg-post`）：

```bash
ffmpeg -f lavfi -i color=black:s=768x1344:r=24 -frames:v 124 \
       -c:v libx264 -preset medium -crf 18 -pix_fmt yuv420p /tmp/v.mp4
ffmpeg -f lavfi -i anullsrc=r=48000:cl=stereo -t 5.1667 -c:a aac /tmp/a.m4a
ffmpeg -i /tmp/v.mp4 -i /tmp/a.m4a -c copy -shortest black.mp4
```

### 片尾定格卡

```bash
ffmpeg -sseof -0.12 -i last_shot.mp4 -frames:v 1 /tmp/last.png
ffmpeg -loop 1 -i /tmp/last.png -t 2.5 -r 24 \
       -vf "scale=768:1344,fade=t=out:st=1.75:d=0.75" \
       -frames:v 60 -c:v libx264 -crf 17 -pix_fmt yuv420p /tmp/card_v.mp4
# 音频同样单独造 2.5s 再 mux
```

### 字幕层：一个 ASS 装完

标题卡 / 提问卡 / 逐镜字幕 / CTA **全部写进同一个 .ass**。
**不要在一个 filtergraph 里串两个 `subtitles=`**——直接报 filter 配置错误。

- 提问卡：`Alignment=5` + `\pos(540,880)` 精确落位，字号 92、字距 6
- 标题卡：`Alignment=8`（顶部居中），主标题 128 + 副标题 54，两级字号拉开
- 普通字幕：`Alignment=2`，`MarginV` 400（避开抖音底栏）
- 必须带 `PlayResX/PlayResY`，否则字号和边距都不是像素概念

## 9. 脚本

`scripts/cards.py`：

| 子命令 | 作用 |
|---|---|
| `black` | 造黑屏卡（音画等长，已验证） |
| `endcard` | 从一段视频的末帧造定格淡出卡 |
| `ass` | 从一个结构 JSON 生成整层 ASS（提问/标题/逐镜字幕/CTA） |

```bash
python3 cards.py black   --dur 5.1667 --size 768x1344 --out clips/S00.mp4
python3 cards.py endcard --from clips/S15.mp4 --dur 2.5 --fade 0.75 --out clips/S16.mp4
python3 cards.py ass     --spec structure.json --total 86.17 --out overlay.ass
```

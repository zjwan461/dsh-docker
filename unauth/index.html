这个站点需要一个登录令牌

This deployment requires the launch token that dsh prints when it starts. 在拿到它之前，界面不会显示。

1 · 在服务器上取出登录链接

docker compose logs dsh | grep -o 'http[^ ]*token=[A-Za-z0-9_-]*' | tail -1

容器名固定时，也可以直接看完整日志：

docker logs -f dsh-dsh-1
  1. 把输出里那一整条地址（含 ?token=…）复制到浏览器打开。
  2. 令牌 每次重启都会重新生成，所以要用最新的一条；旧链接会失效。

2 · 打开一次之后就不必再输

带令牌的链接成功打开一次后，浏览器会得到一个签名的会话 cookie，之后直接访问本站即可。 cookie 的有效期由部署方配置，并与「协议 + 主机 + 端口」绑定 —— 因此 https://主机 与 http://主机:端口 需要各自登录一次。

这一页由反向代理在「未登录的首次访问」时给出，dsh 本身不做任何改动。 · Rendered by the reverse proxy for an unauthenticated first visit; the Harness itself is untouched.
